# ServiceNow Examples & Tutorial Companion

A curated collection of ServiceNow examples organised around tutorial topics and practical platform techniques.

## What this repository contains

The folders cover focused ServiceNow examples such as:

- Dynamic report filters.
- Connect and search-related examples.
- Attachment handling.
- Multi-row variable sets.
- Service Catalog and Knowledge relationships.
- Record Producer data imports.
- Service Portal filter queries.
- GlideAjax.
- Regular expressions.
- Date/time formatting.
- Variable dependencies and validation.

Many folders are named after the tutorial or episode where the example was explored, making the repository useful as a topic-based reference.

## How to use it

1. Choose the folder matching the ServiceNow topic you want to study.
2. Review the scripts or configuration examples.
3. Adapt them in a non-production instance.
4. Validate APIs, security, and supported behaviour against your target ServiceNow release.

## Important note

These examples span older ServiceNow releases and historical platform behaviour. They are best treated as **learning/reference material**, not drop-in production code.

For production use, review:

- Current ServiceNow API guidance.
- ACL and role implications.
- Scope and cross-scope access.
- Upgrade compatibility.
- Error handling and logging.
